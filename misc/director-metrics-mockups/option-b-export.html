Option B — Weekly director export

Idea: No permanent charts on Audit. Operator uses Export (or a dedicated action) to generate a Director week package — CSV and/or short HTML — for the last 7 days.

  • Pros: clean handoff for management; Audit stays uncluttered; same numbers every week.
  • Cons: not live on the page; someone must run the export (or schedule it).
  • Best if: this is a recurring report for your director, not a living dashboard.

1. How the operator triggers it

Same Export modal pattern as Client / Defender / Operator — add a fourth package type (or a separate “Director week” button).

Export report

Choose a package type, then Export.

Output path (example):

~/data/cgi.com-director-week-20260724-20260730.csv
~/data/cgi.com-director-week-20260724-20260730.html
