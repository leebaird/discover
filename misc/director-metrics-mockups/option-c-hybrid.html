Option C — Hybrid

Idea: Light live strip on Audit for the team and a Director week export for the formal management send. One stats engine powers both.

  • Pros: internal awareness + clean handoff; can ship cards first, export second.
  • Cons: two surfaces (keep shared calculation logic).
  • Best if: you need both daily visibility and a weekly artifact for leadership.
Phase 1

Cards + one chart on Audit

Low clutter: KPIs always visible. Optional single “scans per day” chart. Same data as Option A, lighter UI.

Phase 2

Director week export

From Export modal or a “Export week” control on the strip. CSV + short HTML for the director (Option B content).
